PERBAIKAN KATA KUNCI + TOMBOL "SALIN UNTUK OPTIMASI" — SekilasUpdate.com
========================================================================

Paket ini SUDAH MENCAKUP perbaikan kata kunci sebelumnya. Kalau paket
perbaikan-kata-kunci-seo.zip belum sempat dipasang, cukup pasang yang ini.

Ekstrak dari AKAR PROJECT (sejajar package.json), timpa yang lama:
  src/lib/seo.ts                         kata kunci bisa banyak, dipisah koma
  src/components/SeoPanel.tsx            + tombol "Salin untuk Optimasi"
  src/components/ArticleEditorModal.tsx  cuma tambah 1 baris (kategori ikut disalin)

Lalu: npm run lint -> git add -A -> git commit -> git push. Vercel deploy otomatis.

CARA PAKAI TOMBOL SALIN
  Buka Tulis/Edit Berita. Di panel Skor SEO (di atas tombol simpan) ada
  tombol "Salin untuk Optimasi". Klik, lalu tempel (paste) ke chat AI.

  Yang tersalin:
  - kalimat perintah singkat (jangan ubah kutipan, jangan tambah fakta)
  - Judul, Kata Kunci, Kategori, Ringkasan, Isi Berita, Tag
  - status gambar utama
  - skor + semua pemeriksaan (MERAH/ORANYE/KUNING/HIJAU) + angka statistik

KATA KUNCI
  Boleh beberapa frasa dipisah koma. Frasa PALING DEPAN = kata kunci utama.

Tidak ada perubahan database, aturan Firestore, atau environment variable.
